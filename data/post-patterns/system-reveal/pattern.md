# Pattern: system-reveal

Walk through a system or stack the user built, component by component.
This is the lead-magnet engine: the post reveals enough of the system to
prove it works, and frames the complete version as a doc the reader
gets by engaging.

## When to use

- The user has a real system (stack, workflow, set of agents, prompt
  chain) they can describe.
- The reveal is interesting at the component level. A two-step system
  isn't a system; a four-to-seven step one is.
- The hook is `rip`, `stop`, `never`, `credibility`, `nobodys-talking`,
  or `bold-number`.

## Structure

```
Setup (1-2 lines): what the system does.

Component list (4-7 arrows):
→ Component 1: [what it does]
→ Component 2: [what it does]
→ Component 3: [what it does]
→ Component 4: [what it does]

Result block (3 bullets):
→ [real metric or outcome]
→ [real metric or outcome]
→ [real metric or outcome]

Lead-magnet line (1-2 lines): "I just packaged the full system into a doc."
```

## Worked example

```
I built 4 AI agents that flip the model:

→ Agent 1: [what it does]
→ Agent 2: [what it does]
→ Agent 3: [what it does]
→ Agent 4: [what it does]

The result:
→ [real metric]
→ [real metric]
→ [real outcome]

I just packaged the full system into a doc.
```

## Rules

- Each component is one line. Names what it does, not how.
- 4-7 components. Three is a list, not a system. Eight is too many to
  hold in a swipe.
- The result block uses real metrics. If you don't have three real
  metrics, list two or drop the block.
- The lead-magnet line is short. "I just packaged the full system into a
  doc" beats "I've compiled this into a comprehensive resource."
- Real components only. If a component doesn't exist yet, the system
  isn't ready to reveal.

## What NOT to do

- Don't reveal the prompts themselves. The hook is the architecture, not
  the contents.
- Don't pad with adjectives. "Agent 3: Strategically optimizes" is
  filler. "Agent 3: Pulls the prospect's last 10 LinkedIn posts" is a
  component.
- Don't number the agents AND use arrows. Pick one.
- Don't promise a doc you don't have. The CTA points to a real
  deliverable.

## Pairs well with

Hooks: `rip`, `stop`, `never`, `credibility`, `nobodys-talking`,
`bold-number`. CTAs: `keyword-capture` (the doc is the system) or
`generosity-frame` ("I charge for this audit, but here it is").
