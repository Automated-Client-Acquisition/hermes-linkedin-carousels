# Hook: never

Promise the reader they will never suffer through a painful process
again. Line 2 names the new thing that ends the pain.

## Formula

```
Line 1: "NEVER [painful thing] again."
Line 2: "[New thing] just made that entire process obsolete."
```

## When to use

- The painful thing is a real, repeated, recognizable chore the audience
  does (writing cold emails from scratch, manual list-building, etc).
- The new thing actually eliminates the chore, not just speeds it up.
- Voice is `hype`.

## Worked examples

```
NEVER write a cold email from scratch again.
GPT 5.4 just made that entire process obsolete.
```

```
NEVER build a prospect list manually again.
[Specific tool / system] just made that work obsolete.
```

```
NEVER chase a follow-up reply manually again.
The new auto-handler does the entire loop.
```

## Common failure modes

- The replacement doesn't actually eliminate the work. It just moves the
  work somewhere else. Readers can tell.
- The painful thing is universal but the solution is niche. "NEVER write
  cold email again" + "use this $499/mo tool" reads as ad copy.
- The capital NEVER becomes a habit. Two NEVER hooks back-to-back reads
  as a salesperson, not a peer.

## Pairs well with

`system-reveal` post pattern (the body shows the replacement working).
CTAs: `keyword-capture` or `generosity-frame` (the doc inside the
keyword-capture is the actual system).
