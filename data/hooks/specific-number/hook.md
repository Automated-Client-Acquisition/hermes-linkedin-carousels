# Hook: specific-number

Lead with a precise number plus an unexpected outcome. The specificity is
the credibility. Line 2 promises the reveal.

## Formula

```
Line 1: "[Specific number] [outcome] from [specific input]."
Line 2: "No [obvious tactic]. No [obvious tactic]. Just this ↓"
```

## When to use

- The user has a real, specific result they can name.
- The result is interesting at the specific number — "100 meetings" is a
  hook, "lots of meetings" is not.
- Voice is `hype` (best fit) or `senior-operator`. `clean` softens the
  punch.

## Worked examples

```
[N] replies from [N] cold emails.
No fancy tools. No "AI personalization." Just this ↓
```

```
[N] meetings booked from [N] outbound emails last month.
No SDR team. No paid ads. Just this ↓
```

```
[N] qualified leads in [N] days from [N] LinkedIn comments.
No paid tools. No mass DMs. Just this ↓
```

## Common failure modes

- **Fake numbers.** Truth rule overrides everything. If you didn't get
  47 replies from 200 emails, don't write 47/200. Use the user's real
  numbers or skip this archetype.
- The number is round and forgettable ("100 meetings"). Specific beats
  round — 47 outperforms 50.
- Line 2 reads as humble-brag ("I did this with zero effort"). The "no
  X, no Y, just this" frame works because it removes credit, not because
  it adds shine.

## Pairs well with

`breakdown` post pattern (you walk through "just this" step by step) or
`system-reveal` (the post body IS the system). CTAs: `keyword-capture`
(the system goes in a doc).
