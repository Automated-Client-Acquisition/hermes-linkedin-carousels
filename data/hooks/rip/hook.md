# Hook: rip

Declare the old way dead. The "R.I.P" funeral framing is loud, visual,
and easy to scan. Line 2 names the new thing that killed it.

## Formula

```
Line 1: "R.I.P [old way of doing things]."
Line 2: "[New thing] just changed everything."
```

## When to use

- A new tool, model, or technique genuinely makes the old way obsolete.
- The audience cares about the old way (no point eulogizing something
  nobody used).
- Voice is `hype`. `senior-operator` rejects this archetype outright;
  `clean` won't carry the funeral framing.

## Worked examples

```
R.I.P Cold Email Templates.
GPT 5.4 just made them obsolete.
```

```
R.I.P [old workflow].
[Specific new tool] just changed everything.
```

```
R.I.P generic personalization tokens.
The new APIs let you write actual research at scale.
```

## Common failure modes

- The "old way" is still very much alive. Premature obituaries date badly.
- The replacement is hype. The post body has to actually demonstrate the
  shift; a "R.I.P X" hook with no real demonstration reads as content
  marketing for a tool.
- Overuse. If every post is a R.I.P hook, the brand becomes a doomsday
  ticker.

## Pairs well with

`system-reveal` post pattern (the new system that killed the old way) or
`breakdown` (a step-by-step showing the replacement working). CTAs:
`keyword-capture` (a doc showing the new method).
