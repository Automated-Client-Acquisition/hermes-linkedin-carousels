# Layout-system registry

The authoritative list of layout systems that `init.py --layout <name>`
accepts. Each line: `- <name>: one-sentence description`.

- editorial-spread: Magazine-feature-style spreads. Each slide is a hero composition; multiple slides have NO content card; pull-quotes, oversized numerals, full-bleed type, asymmetric weight. Best for confessional / narrative posts.
- dossier-stack: Capability-list teardown. Every slide has a kicker pill + content card + numbered rows + page counter. The current default for capability-reveal posts (R.I.P. teardowns, system-reveal lists).
- newspaper-column: Print-newspaper grammar. Headlines stack horizontally, columns of body type, drop caps, hairline rules between zones, bylined feel. Best for breaking-news, policy, market-analysis posts.
- dispatch-bulletin: Field-report / wire-service feel. Tracked-mono dispatch heads, short paragraph blocks, sparse decoration, single hero element per slide. Best for terse operational announcements, "from the field" updates, founder-letter posts.
