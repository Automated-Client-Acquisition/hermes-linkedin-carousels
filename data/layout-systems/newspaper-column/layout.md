# Layout system: newspaper-column

## The vibe

Print-newspaper grammar. The slide reads like a column from a
serious newspaper — masthead at the top, headline beneath, body
type below, "page fold" footer chrome. Authority through
journalistic format.

## When to use

- Breaking-news / market / policy posts.
- Investigative-feel content where the format itself implies
  authority.
- Posts where the topic naturally suits a journalistic register
  (regulation, M&A, market shifts, industry analysis).

DO NOT use for: confessional posts, capability lists, single-quote
manifestos, light social posts. Newspaper-column carries gravitas;
using it for trivial content reads as ironic.

## How the model uses this

newspaper-column is a journalistic vibe. The visual note describes
the slide's content (the headline, the source attribution, what the
body says, what evidence appears). The model composes visuals that
read as a newspaper column within the locked style's aesthetic
world.

There is no prescription of "every slide uses a dateline strip + a
two-column body + a page-fold footer." Those were defaults that
made every slide identical. The model composes the actual layout
based on the slide's content (a stat reveal slide doesn't need
two-column body; a comparison slide does; an opener doesn't need a
sidebar pull).
